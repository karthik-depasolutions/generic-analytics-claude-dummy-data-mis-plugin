# Claude_dummy_data — Generic Analytics Pack Analyst

Industry-agnostic fallback pack for tabular data that doesn't clearly match a specialized industry pack. Deliberately low-confidence by design — see forge_core.classification.matcher — so it never outranks a genuine industry match, but always provides a usable baseline.

Generated by [MIS Plugin Forge](https://github.com/) — a Claude Code/Desktop plugin, ready to install directly from this repo.

## Install in Claude Code or Claude Desktop

```text
/plugin marketplace add karthik-depasolutions/generic-analytics-claude-dummy-data-mis-plugin
/plugin install generic-analytics-claude-dummy-data-mis-plugin@generic-analytics-claude-dummy-data-mis-plugin
/reload-plugins
```

## Before first use

This plugin reads live from a database - there is no bundled `data/` folder. Set the following in the environment Claude Desktop/Code launches from, using the connection string you were given when this plugin was generated (it is never stored in this repo):

```bash
export FORGE_SOURCE_DB_URL="<connection string given to you separately>"
```

Plugin version `0.1.0`. See `plugins/generic-analytics-claude-dummy-data-mis-plugin/README.md` for the KPIs and setup notes bundled with this specific plugin.
